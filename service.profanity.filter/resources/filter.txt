# Profanity Filter — Word List
# =============================
# One word or phrase per line. Lines starting with '#' are comments and are
# ignored. Edit freely to add or remove words for your household.
#
# Matching is case-insensitive and whole-word, so "ass" will never match
# "class", "pass" or "assessment".
#
# The list is split into tiers. Only the words ABOVE the first dashed line
# are active. Uncomment entries in the lower tiers to switch them on.
#
# Wildcards
# ---------
# A '*' matches exactly ONE character, so "sh*t" matches "shit", "shat" and
# "shut". That makes wildcards blunt: "sh*t" would also mute the harmless
# words "shot" and "shut", and "c*nt" would mute "cent". No entry below uses
# one - the real spellings are written out in full instead, which keeps the
# filter accurate and keeps ordinary dialogue audible. If you add a wildcard
# yourself, check it against everyday words before you save.
#
# Every entry in the active tier is either a word that does not exist in
# ordinary English, or a word that exists but is never used innocently. Words
# that have a common innocent meaning - "ass" (a donkey), "dick" (a name),
# "cock" (a bird), "sod" (turf), "damn", "hell", "god" - are deliberately
# kept OUT of the active tier so that ordinary dialogue stays audible.
# -----------------------------------------------------------------------------

# --- Active: religious exclamations (blasphemy) ---------------------------
# Switched ON deliberately, for households that want these muted.
#
# These are the OATH FORMS - the words as an exclamation - rather than the
# bare words. That matters: muting every "god" would also swallow "thank
# god", "god bless", "God's own country", a character called Godfrey and so
# on, which is exactly the over-muting this list was rebuilt to avoid. The
